# Настройка WebSocket сервера

## Запуск

Для полноценной работы многопользовательского режима необходимо запустить WebSocket сервер:

### Вариант 1: Запуск обоих серверов одновременно (рекомендуется)
```bash
npm run dev:full
```

Эта команда запустит и Next.js сервер (порт 3000) и WebSocket сервер (порт 3001) одновременно.

### Вариант 2: Ручной запуск

В двух отдельных терминалах:

**Терминал 1 - Next.js сервер:**
```bash
npm run dev
```

**Терминал 2 - WebSocket сервер:**
```bash
npm run ws
```

## Порты

- **Next.js приложение:** http://localhost:3000
- **WebSocket сервер:** ws://localhost:3001

## Описание

WebSocket сервер отвечает за:
- Синхронизацию ходов между игроками
- Трансляцию событий игры в реальном времени
- Управление очередью игроков

Без запущенного WebSocket сервера многопользовательский режим не будет работать корректно.
